# Данные, которые нужно предоставить или подтвердить

Сайт не публикует выдуманные сведения. Всё, что ниже не заполнено, на сайте просто не выводится.
После заполнения пересоберите и задеплойте сайт.

## 1. Критично для запуска

Без этого посетителю негде связаться с компанией.

- [ ] **Контакты** — `src/config/company.ts` → `contacts`:
  - `phone` — телефон в читаемом виде, например `+7 (495) 000-00-00` (ссылка `tel:` строится автоматически);
  - `email` — почта для обращений (ссылка `mailto:`);
  - `officeAddress` — адрес офиса для посетителей (если принимаете посетителей);
  - `workingHours` — режим работы.
- [ ] **SMTP для формы заявки** — переменные окружения в панели Timeweb (см. `.env.example`):
  `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM`, `MAIL_TO`.
- [ ] **Домен** — `SITE_URL` в панели Timeweb (или `siteUrl` в `company.ts`). Пока не задан, сайт закрыт от индексации.

## 2. Реквизиты (`src/config/company.ts` → `requisites`)

Выводятся на страницах «О компании», «Контакты», в подвале и в политике обработки персональных данных.

- [ ] ИНН, КПП, ОГРН
- [ ] Юридический адрес
- [ ] Генеральный директор (ФИО) — по желанию
- [ ] Банковские реквизиты: расчётный счёт, банк, БИК, корр. счёт — по желанию
- [ ] Год начала работы для копирайта (`copyrightSince`) — по желанию

## 3. Подтвердить перечни услуг (`src/config/services.ts`)

Пункты с `draft: true` сейчас **скрыты в production**. Удалите у подтверждённых пунктов `draft: true`,
неподтверждённые удалите целиком, недостающие — добавьте.

**Оценочная деятельность**
- [ ] Объекты оценки: недвижимость; транспорт и спецтехника; машины и оборудование; бизнес, доли и акции;
  права требования; ущерб имуществу.
- [ ] Цели оценки: сделки; наследство и нотариат; залог и кредитование; раздел имущества; судебные споры;
  корпоративные процедуры.

**Судебная экспертиза**
- [ ] Виды экспертиз: оценочная (стоимостная); строительно-техническая; землеустроительная; автотехническая;
  товароведческая. Укажите только те, которые компания действительно проводит.

**Экспертные исследования**
- [ ] Подтвердите, что направление оказывается, и типовые задачи: досудебная претензия; проверка расчётов другой
  стороны; рецензирование отчётов и заключений; подготовка позиции к суду.

## 4. Подтвердить формулировки

- [ ] Порядок оплаты (`src/config/content.ts` → `paymentInfo`): безналичный расчёт с ООО «Интегро» по договору
  или счёту, закрывающие документы по завершении работ.
- [ ] Отчёт об оценке может передаваться в электронной форме (FAQ в `content.ts`).
- [ ] Предварительная консультация перед подачей ходатайства о назначении экспертизы (главная, страница услуги, FAQ).
- [ ] Дата редакции политики обработки ПД (`company.ts` → `privacyPolicyDate`) и тексты страниц
  `/politika-konfidencialnosti`, `/soglasie-na-obrabotku` — рекомендуется показать юристу.
  Если почтовый сервис для заявок размещён не в России, учтите требования о локализации (ч. 5 ст. 18 152-ФЗ).
  При подключении веб-аналитики (например, Яндекс Метрики) политику нужно дополнить.

## 5. По желанию — усиливает доверие

Добавляйте только документально подтверждённые сведения.

- [ ] Специалисты (`src/config/team.ts`): ФИО, должность, квалификация, членство в СРО оценщиков, страхование
  ответственности.
- [ ] Сведения об СРО, договорах страхования, свидетельствах — можно добавить отдельным блоком на «О компании».
- [ ] Фотографии офиса или специалистов. Сейчас вместо фото используется схематичное изображение итоговых
  документов (`src/components/sections/DocumentVisual.tsx`); собственные фото подключаются через `next/image`.
- [ ] Ссылки на соцсети/мессенджеры (`company.ts` → `social`).
- [ ] Ориентировочные сроки и цены, если готовы публиковать.
