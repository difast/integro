# Данные, которые нужно предоставить или подтвердить

Сайт не публикует выдуманные сведения. Всё, что ниже не заполнено, на сайте просто не выводится.
Юридические вопросы (уведомление Роскомнадзора, локализация, сроки хранения и т. п.) — в `LEGAL_REVIEW.md`.

## Заполнено

- Полное и сокращённое наименование, ОГРН, ИНН, КПП, юридический адрес, часы связи — `src/config/company.ts`.

## Озвучка ролика

- [ ] Записать текст из `video/VOICEOVER.md` и передать файл. Порядок добавления — `video/README.md`.

## 1. Для запуска приёма заявок

- [ ] **SMTP** — переменные окружения в панели Timeweb (см. `.env.example`): `SMTP_HOST`, `SMTP_PORT`,
  `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM`, `MAIL_TO`. Почтовый сервис — с серверами в России
  (см. `LEGAL_REVIEW.md`, п. 2.2).
- [ ] **Домен** — `SITE_URL` в панели Timeweb (или `siteUrl` в `company.ts`). Пока не задан, сайт закрыт от индексации.

## 2. Контакты (`src/config/company.ts` → `contacts`)

По указанию владельца электронная почта сейчас не публикуется. Когда данные будут утверждены:

- [ ] `phone` — телефон, например `+7 (495) 000-00-00` (ссылка `tel:` строится автоматически);
- [ ] `email` — почта для обращений (ссылка `mailto:`; также указать в разделе 11 политики);
- [ ] `officeAddress` — адрес офиса для посетителей, если отличается от юридического.

## 3. Реквизиты — по желанию (`requisites`)

- [ ] Генеральный директор (ФИО)
- [ ] Банковские реквизиты: расчётный счёт, банк, БИК, корр. счёт
- [ ] Год начала работы для копирайта (`copyrightSince`)

## 4. Подтвердить перечни услуг (`src/config/services.ts`)

Пункты с `draft: true` **скрыты в production**. У подтверждённых удалите `draft: true`, неподтверждённые удалите.

- [ ] Оценка — объекты: недвижимость; транспорт и спецтехника; машины и оборудование; бизнес, доли и акции;
  права требования; ущерб имуществу. Цели: сделки; наследство и нотариат; залог; раздел имущества; судебные
  споры; корпоративные процедуры.
- [ ] Судебная экспертиза — виды: оценочная; строительно-техническая; землеустроительная; автотехническая;
  товароведческая.
- [ ] Экспертные исследования — подтвердить направление и типовые задачи.

## 5. Подтвердить формулировки

- [ ] Порядок оплаты (`src/config/content.ts` → `paymentInfo`).
- [ ] Передача отчёта об оценке в электронной форме (FAQ).
- [ ] Предварительная консультация перед подачей ходатайства о назначении экспертизы.

## 6. По желанию — усиливает доверие

Только документально подтверждённые сведения.

- [ ] Специалисты (`src/config/team.ts`): ФИО, должность, квалификация, членство в СРО, страхование.
- [ ] Сведения об СРО и страховании ответственности (см. `LEGAL_REVIEW.md`, п. 4.3).
- [ ] Ссылки на соцсети (`company.ts` → `social`).
