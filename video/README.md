# Ролик ООО «Интегро» (Motion Canvas)

Рекламный ролик для главной страницы сайта: 59,6 с, 1920×1080, 30 кадров/с. Субтитры вшиты в видео.
Готовые файлы для сайта лежат в `../public/video/` (`integro.mp4`, `integro.webm`, `integro-poster.jpg`).

Отдельный проект со своими зависимостями — на сборку и деплой сайта не влияет.
Motion Canvas распространяется по лицензии MIT, шрифт IBM Plex Sans — по SIL OFL 1.1.

## Структура

| Файл | Что внутри |
| --- | --- |
| `src/timeline.ts` | **единый источник таймингов**: длительность сцен и реплики озвучки (они же субтитры) |
| `src/scenes/main.tsx` | фон-чертёж, шапка раздела, субтитры, расстановка сцен по таймлайну |
| `src/sections/*.tsx` | сцены: проблема, что на кону, решение, основа работы, порядок работы, ценность, призыв |
| `src/lib/brand.ts` | цвета и шрифт (как на сайте) |
| `src/lib/ui.tsx` | общие элементы: подписи, лист документа |
| `VOICEOVER.md` | текст озвучки с таймкодами — генерируется, не редактировать вручную |
| `scripts/` | генерация текста озвучки, рендер кадров, кодирование видео |

Анимации каждой сцены привязаны к началу реплик из `timeline.ts`. Поэтому при изменении таймингов визуал
сдвигается вместе с текстом.

## Команды

```bash
npm ci
npm start              # редактор Motion Canvas: http://localhost:9000
npm run voiceover      # VOICEOVER.md, субтитры .vtt, расшифровка для сайта + проверка темпа речи
npm run typecheck
```

Рендер и сборка видео:

```bash
npm start                                   # в отдельном терминале
FRAMES=1790 npm run render -- <путь к playwright>   # кадры в output/project/*.jpeg
npm run encode                              # MP4 + WebM + постер в ../public/video/
```

Кадры можно отрендерить и вручную: в редакторе — вкладка Video Settings → Render.

## Фоновая музыка

Озвучки в ролике нет (решение владельца 10.11.2026). Звук — спокойная фоновая музыка, синтезированная
скриптом `scripts/music.py`: без сэмплов и чужих записей, поэтому вопросов с авторскими правами нет.

- Длина совпадает с роликом, музыка бесшовно повторяется вместе с ним: все события и реверберация считаются
  по кругу. Гармония — ре мажор, Dmaj9 → Bm9 → Gmaj9 → Asus2, около 64 ударов в минуту.
- `python3 scripts/music.py` создаёт `audio/music.wav`. Файл не хранится в git, а результат всегда одинаковый:
  генератор случайных чисел запускается с фиксированным зерном.
- `npm run encode` берёт музыку, если в `audio/` нет озвучки, и выравнивает её громкость до −20 LUFS.
- На сайте кнопка звука включена (`hasAudio: true` в `src/config/video.ts`). Без нажатия ролик идёт без звука.

## Как добавить озвучку

1. Запишите текст из `VOICEOVER.md` под воспроизведение ролика без звука.
2. Положите файл в `audio/voiceover.wav` (подойдут также mp3, m4a, flac, ogg).
3. Если реплики разошлись с таймкодами, поправьте `start`/`end` реплик и `duration` сцен в
   `src/timeline.ts`, затем выполните `npm run voiceover` и заново отрендерите кадры.
   Для общего сдвига записи используйте переменную `AUDIO_OFFSET` (секунды).
4. Выполните `npm run encode`. Звук нормализуется по громкости и добавляется в MP4 (AAC) и WebM (Opus).
5. На сайте включите кнопку звука: `hasAudio: true` в `src/config/video.ts`.
